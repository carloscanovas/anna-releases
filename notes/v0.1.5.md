UX + correcciones de instalación. Splash Plymouth aún experimental en Pi 5.

- feat(kiosk): el botón "Cerrar sesión" ahora pide confirmación con un modal grande tipo touch (`ConfirmLogoutModal`). Evita logouts accidentales.
- feat(i18n): idioma por defecto del dispositivo es **catalán** (kiosk + panel + repositorios). Usuarios ya existentes mantienen su preferencia previa hasta que la cambien en Ajustes; nuevos pacientes y staff se crean con `language='ca'`.
- fix(pi): `install-pi.sh` desactiva `cloud-init` tras provisionar. Las imágenes de Raspberry Pi Imager lo traen habilitado y emite "Completed socket interaction for boot stage ..." en cada arranque, pisando el splash de Plymouth.
- fix(pi): Plymouth queda visible más tiempo durante el boot. `plymouth-quit.service` recibe un drop-in que añade `ExecStartPre=sleep 8` + `--retain-splash`. En Pi 5 con KMS el framebuffer driver inicializa tarde y sin este margen Plymouth apenas renderizaba.
- fix(pi): `anna.script` simplificado a versión **estática** (sin animaciones). Logos + texto pintados al cargar el script, sin opacity transitions ni spinner. El DSL animado fallaba silenciosamente en Pi 5.
- fix(server): endpoint SSE `/api/admin/device/updates/log/:id` resuelve el 404 cuando el `id` del frontend no coincide exacto con el filename de `apply.sh` (formato de timestamp distinto). Hace fallback buscando el log más reciente por versión.
- feat(release): `release.sh` limpia automáticamente un tag local huérfano (de un run anterior fallido sin push). Permite reintentar releases tras fallos parciales.
- feat(pi): `install-pi.sh` activa journal persistente (`/var/log/journal`) — necesario para `journalctl -b -1` tras reboots espontáneos. Antes los logs vivían en RAM y se perdían.
- feat(pi): `install-pi.sh` integra `cage` (compositor Wayland) de serie. Pi 5 + lightdm+Xorg falla en framebuffer mode; cage funciona en todos los modelos Pi 3B+/4/5 sin distinción. Adiós al paso manual `anna-fix-kiosk-cage.sh` para installs nuevas.

**Pasos manuales post-OTA** (en tu Pi ya provisionada, en orden):

```bash
# 1. Sincronizar scripts (incluye el activador de plymouth nuevo, splash estático).
ssh -t admin@<host> 'sudo bash /opt/anna/current/scripts/pi/bin/anna-sync-system-scripts.sh'

# 2. Reaplicar el theme Plymouth para que recoja el script estático y el drop-in de --retain-splash + sleep:
ssh -t admin@<host> 'sudo bash /opt/anna/current/scripts/pi/bin/anna-install-plymouth.sh && sudo reboot'
```

Tras el reboot deberías ver el splash con los 3 logos + texto durante varios segundos en lugar del flash anterior.
