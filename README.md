# anna-releases

Repositorio de distribución OTA para el dispositivo Anna.

- `manifest.json` — lista de versiones publicadas (consumido por las Pis).
- `anna.pub` — clave pública minisign para verificar firmas.
- `notes/` — release notes por versión.
- GitHub Releases — tarballs firmados.

No editar manualmente. Lo gestiona `scripts/release/release.sh` en el repo `dispositivo-anna`.
